# BaZi scripts

Product-aligned CLIs (from Mystilink BaZi calculator).

```bash
python3 bazi_calculate.py --date 1990-05-01 --hour 14 --timezone Asia/Shanghai
python3 bazi_dayun_calculate.py --date 1990-05-01 --gender female
python3 bazi_liunian_calculate.py --year 2026 --day-stem 甲
```

Stdout JSON. Requires Python 3.9+ (`zoneinfo`).
